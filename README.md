# 212.SU

**212.SU** — сервис сравнения предложений микрофинансовых организаций.

Основной сайт: **https://212.su/**

На сайте можно сравнить предложения по сумме, сроку и полной стоимости кредита (займа), а затем перейти на сайт выбранного кредитора для изучения условий и подачи заявки.

## Важно

212.SU не является банком или микрофинансовой организацией, не выдаёт займы, не принимает решения по заявкам и не гарантирует одобрение. Окончательные условия определяет кредитор.
